# Гирька (Girka)

Тренер по весу, питанию и тренировкам. Прототип для Android и iOS (Flutter), построенный на алгоритмах приложения «Спорт и питание».

Приложение ничего не трекает само: оно берёт дневник питания и вес, показывает честный тренд и говорит, что менять. Все данные хранятся на устройстве, сеть не используется.

## Что есть в прототипе

| Экран | Что делает |
| --- | --- |
| Сегодня | главная мысль дня, план калорий и БЖУ на фактическом расходе, тренд веса, день цикла, ритм недели |
| Прогресс | график веса с трендом (2 недели, 4 недели, 3 месяца), расход энергии, научная основа правил |
| Профиль | цели, импорт и экспорт CSV, демо-данные, язык, удаление данных |

Русский и английский. Светлая и тёмная темы по системе.

## Алгоритмы (`lib/core/`)

- `analytics.dart`: сглаженный тренд веса, наклон за 28 дней с оценкой надёжности, фактический расход (средний приём минус изменение веса), план КБЖУ с нижней границей калорий, правила «главной мысли», день цикла и сравнение с тем же днём прошлого цикла.
- `csv_import.dart`: универсальный разбор CSV (запятая, точка с запятой, табуляция; даты ISO, 28.10.2026, 10/28/2026; русские и английские заголовки; приёмы пищи за день суммируются).
- Правила из исходного приложения сохранены: пропуск не равен нулю, текущий день в расчёт расхода не входит, импорт не перезаписывает ручные значения.

## Чего ещё нет

- Нет автоматической загрузки из Health Connect и HealthKit. Это следующий шаг: пакет `health` и разрешения на обоих платформах.
- Нет базы продуктов и штрихкодов, нет журнала подходов и программ тренировок.
- Правила и ссылки на исследования рассчитаны на общий случай, на других пользователях они не проверялись.
- Формула Миффлина — Сан Жеора используется только как запасной вариант, пока мало данных.

## Сборка и CI

`.github/workflows/build.yml`:
- **Android:** анализ, тесты, подписанный APK. Каждая сборка из `main` публикуется в Releases как `latest`. Секреты: `GIRKA_KEYSTORE_BASE64`, `GIRKA_KEYSTORE_PASSWORD`, `GIRKA_KEY_ALIAS`, `GIRKA_KEY_PASSWORD`. Без них APK подписывается отладочным ключом.
- **iOS:** сборка без подписи на macOS-раннере, результат лежит в артефактах запуска. Для установки на iPhone и TestFlight нужна учётная запись Apple Developer.

В Windows при длинном пути CMake падает (`CXX1429`): собирайте из короткой папки, например `C:\girka`.
